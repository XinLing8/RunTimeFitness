## 📘 Project Overview

The **RUNTIME FITNESS Management System** is a web-based health and wellness platform designed to bridge the gap in personalized fitness and nutrition guidance. Accelerated by the shift toward home workouts following the COVID-19 pandemic, many individuals struggle with generic workout apps that lack tailored dietary support, real-time guidance, or engaging motivational tools.  RUNTIME FITNESS addresses these challenges by offering an all-in-one platform that combines personalized diet planning, structured workout tracking, holistic wellness logging, and community engagement. Developed using the Spiral Model iterative development methodology, the system continuously refines functionalities based on stakeholder feedback and risk assessment.

## ✨ System Features & Core Functionalities

### 👤 Member Features
* **Authentication & Profile Management:** Secure registration and login mechanisms to manage personal details and fitness profiles.
* **Personalised Diet & Workout Plans:** Interactive chatbot feature that gathers personal goals (e.g., weight loss, muscle gain, maintenance) and generates customized meal and exercise plans.
* **Nutritional & Wellness Journal:** Record daily meals (breakfast, lunch, dinner, snacks), water intake, mood, vitamins/supplements, and short personal diary reflections.
* **Workout Progress Logging:** Log completed exercises, duration, and intensity levels to evaluate training consistency over time.
* **Visual Progress Tracking:** Real-time visual metrics using interactive charts to track weight, body measurements (waist, hip, thigh), sleep hours, and hydration.
* **Community Section:** Share thoughts, routines, and experiences with other members to foster long-term commitment.

### 🛠️ Administrator Features
* **Admin Portal:** Secure administrative login and account access.
* **Member Profile Oversight:** Ability to view and edit registered member profiles.
* **Automated System Reporting:** Centralized reporting on member profiles, registrations, and system activity to support administrative evaluations.

### ⚙️ Non-Functional Highlights
* **Performance:** Fast response time under 3 seconds and maximum annual downtime under 50 minutes.
* **Security:** End-to-end encryption of all user health and personal data both at rest and in transit, paired with secure authentication protocols.
* **Usability:** Fully responsive web design ensuring seamless navigation across desktop and mobile devices.
* **Backup & Recovery:** Daily automated backups of user data and automated recovery procedures in case of server failure.
